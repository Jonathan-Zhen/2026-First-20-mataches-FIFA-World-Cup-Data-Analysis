# Dataset

This project uses the FIFA Match, Player and Team Dataset from Kaggle.

Source:

https://www.kaggle.com/datasets/wasiqaliyasir/fifa-match-player-and-team-dataset-2026


Files used in this project:

- matches.csv

The dataset contains:

- Match results
- Possession
- Shots
- Fouls
- Cards
- Attendance
- Team information
