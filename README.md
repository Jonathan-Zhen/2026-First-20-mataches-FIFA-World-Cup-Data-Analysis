# ⚽ What Makes Teams Win? - 2026-First-20-mataches-FIFA-World-Cup-Data-Analysis


## Project Overview

This project explores FIFA World Cup match statistics to identify the key characteristics associated with winning football teams.

Using Python, Pandas and Matplotlib, the analysis investigates how match performance indicators relate to match outcomes through Exploratory Data Analysis (EDA), Feature Engineering and Correlation Analysis.

---

## Business Question

> What characteristics make football teams more likely to win?

---

## Dataset

Source:
FIFA Match, Player and Team Dataset (Kaggle)

## Feature Engineering

Created four new metrics:

- Shot Accuracy
- Goal Conversion Rate
- Shots per Possession
- Shots per Corner

---

## Key Findings

- Winning teams generally recorded higher possession.

- Shots on target showed the largest difference between winning and losing teams.

- Teams committing more fouls tended to lose more frequently.

- Shot Accuracy and Goal Conversion demonstrated a strong positive correlation.

---

## Limitations

- Small sample size (20 matches)

- Only home-team statistics analysed

- Correlation does not imply causation
